# XBoard / V2Board 主题选型与安装前检查

EZ-Theme 是面向 XBoard / V2Board 的 Vue 3 用户前端主题。选择 XBoard 主题、V2Board 主题或其他用户前端时，先核对面板 API、构建命令和部署边界。

## 安装前

1. 确认当前面板类型和 API 路径。
2. 备份现有前端配置和可回滚版本。
3. 根据上游 README 使用实际 package scripts 构建。
4. 在独立环境验证登录、套餐、订单、订阅和国际化。
5. 确认移动端、亮色与暗色模式显示正常。

## 常见搜索问题

### XBoard 主题不生效怎么办？

检查构建产物部署位置、浏览器缓存、API 地址和面板类型。不要在未确认构建成功时直接覆盖线上文件。

### V2Board 前端可以直接用于 XBoard 吗？

两者接口和功能可能存在差异。应以实际代码和面板版本验证，不要仅根据项目标题判断兼容性。

### 这是 Manguo Labs 原创主题吗？

不是。本仓库是 PangHu-Code/EZ-Theme 的原生 Fork，原作者、联系信息、赞助地址和 MIT 声明保留在 README 中。
